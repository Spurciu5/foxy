Install

Download

Get foxnotch.exe from the button above. No installer, nothing else needed.

Run it

If Windows says it protected your PC, click More info → Run anyway. Foxy is new and not signed by a big company yet.

Say hi

Foxy appears at the top of your screen and in the tray. Right click the tray icon for Settings.

Questions

Good to know

Is it free?

Yes, completely.

Does Foxy record what I type?

No. For the stats it only counts how many keys and clicks there were — which key was pressed is never stored or sent anywhere.

What do friends see about me?

Your name, your fox's look, whether you're online, and the song you're playing. Messages between friends aren't stored on the server.

How does it update?

Foxy updates itself, and every update is signed so only real ones are installed. You can turn automatic updates off under Settings › Updates.

How do I remove it?

Right click the tray icon › Quit, then delete the exe. Settings live in %APPDATA%\FoxNotch if you want to remove those too.
